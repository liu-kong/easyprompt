# 数据导入导出

EasyPrompt 提供了强大的数据导入导出功能，支持提示词的迁移、备份和共享。本节将介绍如何使用这些功能。

## 导出功能

### 导出 SQL 命令

1. 在左侧导航栏中点击"数据导出"
2. 选择要导出的项目或提示词
3. 选择导出格式：
   - **INSERT 语句**：用于插入新数据
   - **UPDATE 语句**：用于更新现有数据
4. 点击"导出"生成 SQL 命令
5. 复制或下载生成的 SQL 文件

### 导出 JSON 格式

1. 在"数据导出"页面选择"JSON 格式"
2. 选择要导出的项目或提示词
3. 点击"导出"生成 JSON 文件
4. 下载生成的 JSON 文件

### 导出表结构

1. 在"数据导出"页面选择"表结构"
2. 选择要导出的表
3. 点击"导出"生成建表语句
4. 复制或下载生成的 SQL 文件

## 导入功能

### 导入 SQL 文件

1. 在"数据导出"页面切换到"导入"标签
2. 选择"SQL 文件"导入方式
3. 上传 SQL 文件或粘贴 SQL 内容
4. 选择导入模式：
   - **仅验证**：检查 SQL 语法，不执行
   - **执行导入**：执行 SQL 语句
5. 点击"导入"开始导入过程

### 导入 JSON 文件

1. 在"导入"页面选择"JSON 文件"导入方式
2. 上传 JSON 文件或粘贴 JSON 内容
3. 配置导入选项：
   - **覆盖现有数据**：是否覆盖同名提示词
   - **创建新项目**：是否为不存在的项目创建新项目
4. 点击"导入"开始导入过程

## 多表对比分析

EasyPrompt 支持多表对比分析功能，帮助您了解不同版本或不同环境之间的差异：

1. 在左侧导航栏中点击"多表对比"
2. 选择要对比的表或数据源
3. 选择对比维度：
   - **结构对比**：比较表结构差异
   - **数据对比**：比较数据内容差异
   - **版本对比**：比较不同版本之间的差异
4. 点击"开始对比"生成对比报告
5. 查看对比结果和差异详情

## 数据迁移场景

### 开发环境到生产环境

1. 在开发环境导出数据
2. 根据生产环境需求调整导出内容
3. 在生产环境导入数据
4. 验证导入结果

### 项目间数据共享

1. 导出项目数据为 JSON 格式
2. 将 JSON 文件分享给其他团队
3. 其他团队导入 JSON 文件
4. 根据需要调整导入的数据

### 数据备份

1. 定期导出完整数据
2. 保存导出文件到安全位置
3. 在需要时恢复数据

## 导出选项

### 数据筛选

- **按项目筛选**：只导出指定项目的数据
- **按时间筛选**：只导出指定时间范围内的数据
- **按状态筛选**：只导出激活或停用的数据

### 格式选项

- **包含 ID**：是否包含记录 ID
- **包含时间戳**：是否包含创建和更新时间
- **格式化输出**：是否格式化 SQL 语句

## 导入选项

### 冲突处理

- **跳过冲突**：遇到冲突时跳过该记录
- **覆盖冲突**：遇到冲突时覆盖现有记录
- **重命名冲突**：遇到冲突时自动重命名

### 验证选项

- **语法验证**：验证 SQL 语法
- **数据验证**：验证数据完整性
- **引用验证**：验证外键引用

## 最佳实践

1. **定期备份**：定期导出数据作为备份
2. **测试导入**：在生产环境导入前先在测试环境验证
3. **版本控制**：对导出文件进行版本控制
4. **文档记录**：记录导入导出的操作和结果
5. **权限管理**：限制导入导出功能的访问权限

## 常见问题

### 导入失败
- 检查文件格式是否正确
- 验证数据是否符合约束
- 确认权限是否足够

### 数据冲突
- 使用冲突处理选项
- 手动解决复杂冲突
- 考虑使用增量导入

### 性能问题
- 分批导入大量数据
- 在非高峰期执行导入
- 优化数据库配置
