# EasyPrompt 介绍

EasyPrompt 是一个简单易用的提示词管理平台，旨在简化和优化提示词的管理、版本控制和部署过程。

## 主要特点

- **多数据库支持**：支持 SQLite、MySQL 和 PostgreSQL 数据库
- **提示词管理**：快速创建、编辑和管理提示词
- **版本控制**：支持项目和提示词的版本管理
- **数据迁移**：支持提示词的导出和导入
- **多表对比**：支持多表对比分析，明确内容差异
- **代码生成**：支持 Python、Java、Go 语言快速构建智能体
- **现代化界面**：基于 Vue3 + TypeScript 的现代化用户界面

## 适用场景

EasyPrompt 适用于以下场景：

- AI 应用开发团队需要管理和共享提示词
- 需要对提示词进行版本控制和协作开发
- 需要在不同环境间迁移提示词配置
- 需要对比和分析不同版本的提示词效果
- 需要快速生成基于提示词的代码框架

## 技术栈

- **前端**：Vue3 + TypeScript + Pinia
- **后端**：Node.js + Express + TypeScript
- **数据库**：SQLite/MySQL/PostgreSQL
- **部署**：Docker
