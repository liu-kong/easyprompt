# 数据库配置

EasyPrompt 支持多种数据库类型，可以根据需求选择合适的数据库。本节将介绍如何配置和管理数据库连接。

## 支持的数据库类型

- **SQLite**：默认数据库，适合开发和小型部署
- **MySQL**：适合中大型部署，支持高并发
- **PostgreSQL**：适合大型部署，支持高级 SQL 功能

## 数据库配置界面

1. 在左侧导航栏中点击"数据库配置"
2. 查看当前已配置的数据库列表
3. 点击"新增数据库配置"添加新的数据库连接

## 配置 SQLite 数据库

SQLite 是默认的数据库类型，无需额外安装：

1. 点击"新增数据库配置"
2. 填写配置信息：
   - **名称**：配置的显示名称
   - **类型**：选择"SQLite"
   - **数据库**：数据库文件路径（如：./data/easyprompt.db）
3. 点击"测试连接"验证配置
4. 点击"保存"完成配置

## 配置 MySQL 数据库

1. 确保已安装并运行 MySQL 服务
2. 点击"新增数据库配置"
3. 填写配置信息：
   - **名称**：配置的显示名称
   - **类型**：选择"MySQL"
   - **主机**：MySQL 服务器地址（如：localhost）
   - **端口**：MySQL 端口（默认：3306）
   - **数据库**：数据库名称
   - **用户名**：数据库用户名
   - **密码**：数据库密码
4. 点击"测试连接"验证配置
5. 点击"保存"完成配置

## 配置 PostgreSQL 数据库

1. 确保已安装并运行 PostgreSQL 服务
2. 点击"新增数据库配置"
3. 填写配置信息：
   - **名称**：配置的显示名称
   - **类型**：选择"PostgreSQL"
   - **主机**：PostgreSQL 服务器地址（如：localhost）
   - **端口**：PostgreSQL 端口（默认：5432）
   - **数据库**：数据库名称
   - **用户名**：数据库用户名
   - **密码**：数据库密码
4. 点击"测试连接"验证配置
5. 点击"保存"完成配置

## 数据库连接管理

### 测试连接
在保存配置前，建议先测试连接以确保配置正确：
1. 填写完配置信息后点击"测试连接"
2. 系统会尝试连接数据库并返回结果
3. 连接成功后才能保存配置

### 编辑配置
1. 在数据库配置列表中找到要修改的配置
2. 点击配置右侧的"编辑"按钮
3. 修改配置信息
4. 点击"测试连接"验证新配置
5. 点击"保存"确认修改

### 删除配置
1. 在数据库配置列表中找到要删除的配置
2. 点击配置右侧的"删除"按钮
3. 在确认对话框中点击"确认删除"

**注意**：删除数据库配置不会删除数据库中的数据，只是删除连接配置。

## 数据库迁移

当切换数据库时，可能需要迁移数据：

1. 从原数据库导出数据
2. 在新数据库中创建表结构
3. 将数据导入新数据库

详细步骤请参考[数据导入导出](./import-export.md)。

## 数据库最佳实践

1. **定期备份**：定期备份数据库，防止数据丢失
2. **权限控制**：使用专用数据库用户，限制权限
3. **连接池**：在生产环境中使用连接池提高性能
4. **监控**：监控数据库性能和连接状态
5. **安全**：使用 SSL 连接，保护数据传输安全

## 常见问题

### 连接失败
- 检查数据库服务是否运行
- 验证连接参数是否正确
- 确认网络连接是否正常
- 检查防火墙设置

### 权限问题
- 确保数据库用户有足够的权限
- 检查文件系统权限（SQLite）
- 验证数据库用户名和密码

### 性能问题
- 优化数据库查询
- 添加适当的索引
- 考虑使用连接池
- 定期维护数据库
