# 提示词管理

提示词是 EasyPrompt 平台的核心内容，用于指导 AI 模型生成期望的输出。本节将介绍如何创建、管理和使用提示词。

## 创建提示词

1. 在左侧导航栏中点击"提示词管理"
2. 点击"新增提示词"按钮
3. 填写提示词信息：
   - **所属项目**：选择提示词所属的项目
   - **提示词代码**：提示词的唯一标识符（用于代码生成）
   - **提示词名称**：提示词的显示名称
   - **提示词内容**：实际的提示词文本
   - **备注**：可选的额外信息
4. 点击"保存"创建提示词

## 提示词列表

提示词列表页面显示所有已创建的提示词，支持两种视图模式：

### 卡片视图
- 以卡片形式展示提示词
- 显示基本信息和部分内容
- 适合快速浏览和少量提示词

### 表格视图
- 以表格形式展示提示词
- 显示完整信息
- 适合大量提示词的管理和查找

## 编辑提示词

1. 在提示词列表中找到要编辑的提示词
2. 点击提示词右侧的"编辑"按钮
3. 修改提示词信息
4. 点击"保存"确认修改

## 删除提示词

1. 在提示词列表中找到要删除的提示词
2. 点击提示词右侧的"删除"按钮
3. 在确认对话框中点击"确认删除"

**注意**：删除提示词会同时删除其所有版本历史，此操作不可恢复。

## 提示词版本管理

EasyPrompt 支持提示词的版本管理，可以跟踪提示词的变更历史：

1. 在提示词列表中点击提示词名称
2. 在提示词详情页面查看版本历史
3. 可以比较不同版本之间的差异
4. 可以回滚到之前的版本

## 提示词搜索

提示词列表支持搜索功能：

- **按名称搜索**：在搜索框中输入提示词名称
- **按代码搜索**：在搜索框中输入提示词代码
- **按内容搜索**：在搜索框中输入提示词内容关键词

## 提示词代码

提示词代码是提示词的唯一标识符，用于：

- 在代码中引用提示词
- 生成代码时的变量名
- API 调用时的标识符

提示词代码应遵循以下规则：

- 只能包含字母、数字和下划线
- 必须以字母开头
- 在同一项目中必须唯一
- 建议使用有意义的名称

## 提示词最佳实践

1. **清晰命名**：使用清晰、有意义的提示词名称和代码
2. **详细描述**：在备注中提供详细的使用说明
3. **版本管理**：定期创建重要版本，便于回滚
4. **分类组织**：使用项目对提示词进行分类管理
5. **测试验证**：创建提示词后进行测试，确保效果符合预期

## 提示词示例

### 简单提示词
```
请解释什么是人工智能，用简单的语言，适合初学者理解。
```

### 带变量的提示词
```
请解释{topic}，使用{language}语言，适合{audience}理解。
```

### 结构化提示词
```
角色：你是一个专业的{role}
任务：请{task}
要求：
1. {requirement1}
2. {requirement2}
3. {requirement3}
输出格式：{format}
```
