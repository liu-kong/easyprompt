# 项目管理

EasyPrompt 中的项目是组织和管理提示词的基本单位。每个项目可以包含多个提示词，并且支持版本控制。

## 创建项目

1. 在左侧导航栏中点击"项目管理"
2. 点击"新增项目"按钮
3. 填写项目信息：
   - **项目名称**：项目的唯一标识符
   - **项目描述**：项目的详细说明
   - **备注**：可选的额外信息
4. 点击"保存"创建项目

## 项目列表

项目列表页面显示所有已创建的项目，包括以下信息：

- **项目名称**：项目的名称
- **描述**：项目的描述信息
- **提示词数量**：项目中包含的提示词总数
- **创建时间**：项目的创建时间
- **更新时间**：项目的最后更新时间
- **状态**：项目的当前状态（激活/停用）

## 编辑项目

1. 在项目列表中找到要编辑的项目
2. 点击项目右侧的"编辑"按钮
3. 修改项目信息
4. 点击"保存"确认修改

## 删除项目

1. 在项目列表中找到要删除的项目
2. 点击项目右侧的"删除"按钮
3. 在确认对话框中点击"确认删除"

**注意**：删除项目会同时删除项目中的所有提示词，此操作不可恢复。

## 项目状态

项目有两种状态：

- **激活**：项目处于活跃状态，可以正常使用
- **停用**：项目处于停用状态，暂时不可用

可以通过点击状态开关来切换项目状态。

## 项目与提示词的关系

- 每个提示词必须属于一个项目
- 删除项目会同时删除项目中的所有提示词
- 项目中的提示词可以独立进行版本管理

## 项目最佳实践

1. **合理命名**：使用清晰、有意义的项目名称
2. **详细描述**：提供详细的项目描述，便于团队成员理解
3. **定期整理**：定期检查和整理项目，删除不再使用的项目
4. **权限管理**：根据团队需要，合理分配项目访问权限
